# 7. Interface Design Description

This section describes the primary graphical user interface screens, wireframe layouts, and navigational components for both Student and Administrator roles.

| Screen ID & Name | Target Role | Layout & Component Specification |
| :--- | :--- | :--- |
| **SCR-01: Student Quiz Dashboard** | Student | **Header navigation bar** (Home, My Exams, Results, Profile). <br> **Main section** displays active quizzes in card grid format showing Title, Subject, Duration, and 'Start Quiz' button. <br> **Top search bar** allows filtering by keywords. |
| **SCR-02: Exam Attempt & Timer Interface** | Student | **Top persistent banner** featuring Quiz Title, Progress Bar (e.g. Question 5 of 20), and a dynamic red Countdown Timer. <br> **Center panel** displays Question text and radio button choices. <br> **Right sidebar** displays a Question Grid palette allowing jump navigation and highlighting answered vs flagged questions. |
| **SCR-03: Result & Breakdown View** | Student | **Summary card** presenting Total Score, Pass/Fail Badge, Correct Count, Time Elapsed, and 'Return to Dashboard' button. <br> **Detailed accordion list** below shows question-by-question breakdown, student choices, and correct answer explanations. |
