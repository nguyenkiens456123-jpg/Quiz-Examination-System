# 1. FUNCTIONAL REQUIREMENTS

## 1.1. Student Module
- **FR-ST-01:** The system shall allow students to register a new account and securely log in.
- **FR-ST-02:** The system shall display a dashboard listing all available quizzes for the student.
- **FR-ST-03:** The system shall allow students to select and attempt a quiz with a real-time countdown timer.
- **FR-ST-04:** The system shall allow students to navigate between questions and select multiple-choice options.
- **FR-ST-05:** The system shall automatically record student responses and calculate the final score upon quiz submission or time expiration.
- **FR-ST-06:** The system shall allow students to view their historical quiz results and performance breakdown.

## 1.2. Admin / Teacher Module
- **FR-AD-01:** The system shall allow administrators to log in securely with administrative privileges.
- **FR-AD-02:** The system shall allow administrators to create, update, and delete quizzes (title, duration, passing score).
- **FR-AD-03:** The system shall allow administrators to manage question banks (add, edit, remove questions and answer choices).
- **FR-AD-04:** The system shall allow administrators to view and manage student user accounts.
- **FR-AD-05:** The system shall generate statistical reports on student scores and quiz completion rates.
